## プロダクトの紹介
- DEV20期 福岡の、はじめの1か月（10/24〜11/14）で習ったコード 138 項目を、1項目1ページのメモ帳にしました
- 「そういえば習ったよなー」くらいのうろ覚えから、**何回目の・何日の講義で習ったか**にたどり着けます
- 1ページに **コード名・読み方・覚え方・意味・使い方・注意点** をまとめています
- わかったら「わかった」スタンプ → そのページは**見え消し**（取り消し線で残る）。その日の分が全部わかったら「理解した」のはんこが押されます
- わからないところには「よーわからん」スタンプ。あとで「よーわからん」だけを集めて見直せます
- 気づいたことは「自分のメモ」に書けます（日付つき）
- 同期のみんなに使ってもらえたらうれしいです

## 使い方
1. 上の検索欄に、思い出せる言葉を入れる（例：「保存」「ランダム」「ろーかる」「10/31」「第2回」「消したい」）
2. ◀ ▶（スマホは左右にすべらせる）でめくる
3. 「一覧」で全体を、「回・日付から」で講義の日ごとに見る
4. 「いつも使ってるAIに投げるプロンプトをコピー」で、そのページの内容をAIに聞ける形でコピーできる（コピーした文は画面にも出る）

## 工夫した点、こだわった点
- うろ覚えでも当たる検索（ひらがな・カタカナ・全角半角のちがいを気にしない／「〜したい」でも探せる）
- 習った回と日付をいちばん上に出して、「あの日のあれだ」と思い出しやすくした
- わかったら消すのではなく、見え消しで残す（あとで見返せる）
- スタンプは押すと「ポン」と動く
- 第4回で習った **配列・オブジェクト・for・localStorage・JSON** だけで作った
  - スタンプと自分のメモは `localStorage` に JSON で保存
  - 「書き出す」でファイルに控えを取り、別のパソコンで「読み込む」

## 苦戦した点、共有したいハマりポイント
- localStorage は文字しか入らない → オブジェクトは `JSON.stringify` してから保存、取り出したら `JSON.parse`
- 保存はそのパソコンのそのブラウザだけ。履歴を消すと消えるので「書き出す」を付けた
- 検索でカタカナとひらがなを同じに見るために、文字の番号をずらして変換した
